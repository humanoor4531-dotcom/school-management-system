# EduManage — School Management System

A responsive front-end school management website built with HTML, CSS and JavaScript.

## Features

- Dashboard with student, course and attendance summaries
- Add, search and remove student records
- Mark attendance as Present, Absent or Not marked
- Course overview
- Responsive layout for desktop, tablet and mobile
- Browser local storage keeps student and attendance data on the same device

## Files

- `index.html` — website structure
- `style.css` — layout, colors and responsive styling
- `script.js` — dashboard, student and attendance functionality

## Run the website

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

No installation or build tools are required.

## Publish with GitHub Pages

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish. The published URL will appear in the Pages settings.

## Note

This is a front-end demonstration. Student and attendance records are saved in the browser's local storage on the device being used. It does not currently include a server, database, login system or cloud synchronization.
